The installation batch is developped for the Windows version.

Simply download all files in the same repertory, than create the FREECAD_HOME environnement variable with the FreeCAD base repertory.
By example: %FREECAD_HOME% "C:\Users\Admin\Documents\FreeCAD_1.1.3-Windows-x86_64-py311"
